# Данные подрядчиков

Источник: официальные материалы кейса «Умный подбор подрядчиков (#79-lite)».

- `hackathon-dataset-anonymized.csv`: официальный анонимизированный каталог, 66 профилей. Имена вымышленные; `synthetic` отмечает полностью синтетические профили, `city_imputed` и `price_imputed` — значения, проставленные при подготовке данных.
- `hackathon-dataset-preview.html`: предоставленное HTML-превью каталога.

CSV использует UTF-8, разделитель запятую, списки `categories`, `event_formats`, `languages`, `busy_dates` разделены `|`. Флаги имеют значения `True`/`False`; пустые `price_from_kzt` и `max_hours` загружаются как `None`. Даты занятости имеют формат YYYY-MM-DD.

Загрузчик также принимает эквивалентный `.jsonl` со списками JSON, булевыми значениями и `null`. JSONL-файл в текущую поставку не входит. Путь можно изменить через `DATA_PATH`; по умолчанию используется официальный CSV.

`tests/fixtures/profiles_sample.csv` — отдельно созданные 10 синтетических профилей для тестов, все с `synthetic=True`; они не добавляются в официальный каталог.

Сетка использует существующие сочетания город/категория/формат из официальных 66 профилей, даты 23.09, 15.10, 14.11, 31.12.2026 и бюджеты 500000, 1000000, 4000000 ₸, без языка и часов. API-ключ и модель отключены в процессе. Проверяются допустимость показанных кандидатов, число карточек, объяснение малой/пустой выдачи, 1–2 предложения и отсутствие одинаковых текстов после удаления имён. Поле stats содержит только встретившиеся счётчики; отсутствие счётчика нарушения вместе с пустым examples означает ноль обнаруженных случаев. Это ограниченная проверка, не доказательство для любого ввода.

Живые JSON содержат фактические ответы сервиса с gpt-5.4-mini: параметры запроса, время, карточки, факты, оценки, источник объяснения и причину fallback, если он был. У LIVE_BANDS один объект запроса/ответа; у LIVE_TIED массив runs. Время — время HTTP-запроса в этой среде, не универсальный SLA. Порядок и факты следует оценивать отдельно от качества формулировок.
